# Candidate venues (2027)

Researched 2026-10-31 from official pages only (workshop sites, conference sites, the ACL joint call). Every row cites
its source. **Confirmed** = a 2027 page states it. **Unconfirmed** = no 2027 call found; the 2026 (or last) edition's
dates are given as a guide and labelled *guide*. Scope rule: keep only venues whose notification falls before
October 2027.

The draft uses the ACL format, so an ACL-family workshop needs no reformatting. ML workshops (ICLR/ICML/NeurIPS) and
AISec use their own templates. Archival matters: an **archival** workshop paper is a publication, so the same work
generally cannot then go to a main venue. A **non-archival** slot (or the non-archival option many ACL workshops
offer) keeps that path open.
